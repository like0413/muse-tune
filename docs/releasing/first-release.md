# Muse Tune 1.0.0

Muse Tune 是一款面向 Windows 11 的任务栏媒体控制器。它读取 Windows 媒体会话，在任务栏展示当前歌曲，并提供播放控制。

## 功能

- 展示歌曲封面、名称、歌词、播放进度和实时音频频谱；可调整任务栏位置、布局和外观。
- 支持播放、暂停、切歌，以及当前播放器音量或系统主音量控制。
- 提供单行与双行歌词、逐字高亮、翻译、简繁转换和时间偏移等设置。
- 适配 QQ 音乐、网易云音乐、汽水音乐、酷狗音乐和 Spotify；实际可用信息取决于播放器提供的媒体会话。
- 提供系统托盘、开机自启、版本检查，以及简体中文、繁體中文和 English 界面。

## 下载

- 安装版：`MuseTune-1.0.0-windows-x64.exe`，支持应用内更新。
- 便携版：`MuseTune-1.0.0-windows-x64-portable.zip`，解压运行；更新时需手动替换程序文件。

系统要求：Windows 11 x64。使用说明见 [README](https://github.com/like0413/muse-tune#readme)。
